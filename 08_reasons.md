# Каталог причин отказа и NEED_MORE_DATA — кейс 2

## Как заполнять

В applications.csv есть колонка reason. Все уникальные значения должны быть в таблице. Два кода даны как образец.

## Образец (не трогать)

| reason           | Категория | Когда возникает   | Что показать клиенту                         |
| ---------------- | --------- | ----------------- | -------------------------------------------- |
| LOW_INCOME       | Отказ     | income < минимума | «Недостаточный доход для данного продукта»   |
| AGE_OUT_OF_RANGE | Отказ     | age < 18 или > 70 | «Возраст не соответствует условиям продукта» |

## Ваша таблица — заполните 7 кодов

| reason             | Категория             | Когда возникает          | Что показать клиенту                                   |
| ------------------ | --------------------- | ------------------------ | ------------------------------------------------------ |
| INVALID_EMPLOYMENT | Отказ                 | emplment = unemployed    | «Продукт не доступен при текущем статусе занятости»    |
| MISSING_INCOME     | Нужны данные          | income пуст              | «Укажите доход»                                        |
| HIGH_DTI           | Отказ                 | dti > 0.5                | «Слишком высокая долговая нагрузка»                    |
| BKI_DELINQUENCY    | Отказ                 | bki < 500 or delinquency | «Есть просрочки в кредитной истории»                   |
| SMEV_MISMATCH      | Отказ/Ручная проверка | smev = MISMATCH          | «Данные не совпали при проверке, обратитесь в банк»    |
| AMOUNT_LIMIT       | Отказ                 | amount > 10 x income     | «Сумма кредита превышает допустимую для вашего дохода» |
| EXTERNAL_TIMEOUT   | Нужны данные          | BKI/СМЭВ timeout         | «Не удалось проверить данные, попробуйте позже»        |
| LOW_INCOME         | Отказ                 | income < минимума        | «Недостаточный доход для данного продукта»             |
| AGE_OUT_OF_RANGE   | Отказ                 | age < 18 или > 70        | «Возраст не соответствует условиям продукта»           |

## Критерий приёмки

- [ ] Все reason из applications.csv покрыты
- [ ] Указана категория: Отказ / Нужны данные / Ручная проверка
- [ ] «Что показать клиенту» — понятный текст, не машинный код
- [ ] Нет причины, которой нет в applications.csv
- [ ] EXTERNAL_TIMEOUT — категория «Нужны данные», не «Отказ»

## Подсказки

- reason — машинный код (UPPER_SNAKE_CASE), «что показать» — человеческий текст.
- HIGH_DTI → «Слишком высокая долговая нагрузка».
- BKI_DELINQUENCY → «Есть просрочки в кредитной истории».
- SMEV_MISMATCH → «Данные не совпали при проверке, обратитесь в банк».
- MISSING_INCOME → «Укажите доход».
- EXTERNAL_TIMEOUT → «Не удалось проверить данные, попробуйте позже».
