# Отчёт о тестировании интерактивного режима `04_прототип.py`

## Область тестирования
Проверен именно диалоговый запуск без аргументов командной строки: путь к файлу заявок, выбор режима, путь сохранения результата и вопрос о выводе расхождений.

## Результаты

| № | Сценарий | Фактический результат | Статус |
|---|---|---|---|
| INT-01 | Все ответы оставить пустыми | Используются значения по умолчанию; обрабатываются 100 заявок | Пройден |
| INT-02 | Ввести несуществующий путь к CSV | Программа падает с `FileNotFoundError` и traceback | Ошибка |
| INT-03 | Ввести путь Windows с обратными слешами, которого нет | На тестовой Linux-среде путь не найден; `FileNotFoundError`. На Windows такой формат пути корректен, если файл существует | Ошибка обработки неверного пути |
| INT-04 | В режиме ввести `abc`, затем `2` | Программа выводит «Введите 1 или 2», повторяет вопрос и принимает `2` | Пройден |
| INT-05 | В вопросе y/n ввести `t` | Программа молча воспринимает ответ как «нет», продолжает работу | Ошибка валидации ввода |
| INT-06 | В вопросе y/n ввести `y` | Программа выводит все 22 расхождения в режиме сверки | Пройден |
| INT-07 | Указать недоступный путь для выходного файла (`/proc/out.csv`) | Падает при создании `audit.log` с `FileNotFoundError`, traceback | Ошибка обработки пути сохранения |
| INT-08 | Завершить ввод EOF сразу | `input()` перехватывает `EOFError`, подставляются значения по умолчанию, программа запускается | Замечание: EOF не отличим от намеренного пустого ввода |

## Подробности дефектов

### DEF-INT-01. Несуществующий путь к файлу заявок не обрабатывается
**Шаги:** запустить `python 04_прототип.py` без аргументов; на вопрос «Путь к заявкам» ввести `no_such_file.csv`; остальные вопросы заполнить значениями по умолчанию.

**Фактический результат:** необработанное исключение `FileNotFoundError`, выводится traceback, приложение завершается.

**Ожидаемый результат:** понятное сообщение, например:
`Ошибка: файл заявок 'no_such_file.csv' не найден. Проверьте путь и повторите ввод.`
После сообщения желательно повторно запросить путь, а не аварийно завершать программу.

**Исправленно:** [ ] да [x] нет

### DEF-INT-02. Вопрос y/n принимает любой неизвестный ответ как «нет»
**Шаги:** запустить программу; на вопрос «Показать расхождения с CSV (y/n)» ввести `t`.

**Фактический результат:** `t` превращается в `False`, программа продолжает работу без предупреждения.

**Ожидаемый результат:** принимать только `y` или `n` (без учёта регистра); при любом другом значении вывести `Введите y или n` и повторить вопрос.

**Исправленно:** [ ] да [x] нет

### DEF-INT-03. Путь выходного файла не проверяется до обработки заявок
**Шаги:** указать `/proc/out.csv` в поле «Куда писать результат».

**Фактический результат:** программа падает при записи `audit.log` в `/proc`, ещё до формирования итогового CSV. Ошибка сопровождается traceback.

**Ожидаемый результат:** до обработки заявок проверить, что каталог назначения существует и доступен для записи; при ошибке показать понятное сообщение и повторно запросить путь.

**Исправленно:** [ ] да [x] нет

### DEF-INT-04. EOF автоматически подставляет значения по умолчанию
**Шаги:** запустить приложение и передать конец ввода сразу, не отвечая на вопросы.

**Фактический результат:** каждый `EOFError` трактуется как пустая строка, затем используются значения по умолчанию; программа запускает обработку.

**Ожидаемый результат:** если пользователь прервал ввод или поток ввода закончился, приложение должно сообщить об отмене и завершиться без обработки, либо явно документировать такое поведение.

**Исправленно:** [ ] да [x] нет
